# 墨骰工坊 · InkDice

让填卡少一点繁琐，让冒险多一点自由。

墨骰工坊是一款以方便玩家填卡为目标的 Windows 桌面人物卡工具，由 [ZerDarOn](https://github.com/ZerDarOn) 开发与维护。

## 目前可以做什么

- 分别创建 D&D 5E（2014）、5R（2024）和 CoC 七版人物卡。
- 查询对应系统资料，使用候选与自动填入，同时保留手动修改能力。
- 管理人物、装备、法术等信息，导出 JSON 备份与多工作表 Excel。
- 使用悬浮助手、3D 骰子，以及自行配置服务的 AI 人物问答。
- 导入、启用和停用纯 JSON 资料包。可执行脚本插件与外部新规则系统接口尚未开放。

项目仍在迭代，资料收录与自动化不代表覆盖全部出版物或所有规则效果。AI 回答可能有误，请核对引用和原始资料。
