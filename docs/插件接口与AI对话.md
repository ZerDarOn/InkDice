# 当前接入范围

截至 2026-10-27，应用支持纯资料包扩展。通用可执行插件宿主尚未实现，不把旧架构设计文件视为已可用的运行时接口。

| 扩展点 | 当前状态 | 实际入口 |
| --- | --- | --- |
| JSON 资料包导入、校验 | 已实现 | `validatePack`、`PackRegistry.install` |
| 启用、停用、移除、导出 | 已实现 | 设置 → 插件与资料包，变更立即影响当前窗口 |
| 分规则检索、详情、统计 | 已实现 | `extendedLibraryRequest` 叠加内置库与启用包 |
| 填卡候选自动带入 | 已实现范围内 | D&D 法术、武器、奇物、普通物品；CoC 武器、防护物；其他条目供检索 |
| AI 使用资料包 | 已实现 | 与内置库走同一检索入口，按卡片系统筛选并附来源 |
| 外部规则适配器／新系统 | 未开放 | 目前 5E、5R、CoC 为内置实现 |
| 外部界面页面、导出器 | 未开放 | 尚无注册、卸载、隔离和资源回收协议 |
| 外部 JS／网络权限 | 未开放 | 不导入脚本，不执行包内效果对象 |

当前纯资料格式见 `schemas/runtime-content-pack.schema.json`，运行时校验以 `prototype/content-packs.mjs` 为准。旧 `schemas/content-pack.schema.json` 是早期未来设计，不是当前可导入格式。没有悄悄宣称兼容尚未接入的字段。

启停的生命周期是：先校验并成功保存新注册表 → 更新当前窗口内存 → 关闭旧候选、失效旧检索 → 刷新查询器、取消进行中的 AI 请求。已经抄入卡片的文字或数值保持不变。包不会自动修改卡片、添加算法或执行外部代码。

以后开放可执行插件前，仍需确定 API 版本、能力声明与权限、沙箱消息协议、注册/卸载与资源清理、版本冲突和崩溃隔离；这些不能仅用一个导入按钮替代。

# AI 对话

悬浮球 → AI，填写问题并发送，或按 Ctrl/Cmd + Enter。使用设置中已保存的聊天补全兼容服务以及当前会话密钥。配置测试和对话共用端点规则，后者调用 `/api/ai/chat`，不是固定连接测试。

每次发送时生成当前人物摘要，附上同一系统的本机资料摘录和本人物最近 6 轮对话。属性、生命、熟练和技能尽量使用现有计算器输出；原始基础属性与自动生效属性分别列出。立绘、玩家名、其他人物和配置密钥不进入模型消息。发送摘要前可以在面板里展开查看。自己写入背景或描述的内容仍可能包含个人信息，发送内容以预览为准。

检索优先使用问题中的已有条目名、引号名称与关键词；「这个」「它」「继续」等追问会参考上一问题。最多 8 次关键词查询、8 条摘录，每条正文最多 3200 字符。长卡截取列表并标明，**不是全文语义索引，也不能保证所有规则都被检索到**。匹配失败会明确告知模型资料不足，不捏造替代条目。

资料与卡片作为不可信数据放入用户消息，固定系统消息要求按本次系统作答、区分数据与指令、引用 `[S1]` 等本次来源、无依据则说明。模型输出只显示为文本，不执行 HTML、链接代码或工具指令。来源面板显示实际发送的摘录，未匹配的引用编号会提示；引用编号存在不代表模型解释必然正确。

聊天历史按人物 ID 和规则版本分开，本窗口内保存最近 12 轮，刷新后清空。切换人物或停用资料包会取消未完成请求，迟到响应不会放进另一人物记录。可停止生成；失败保留问题供重试。服务请求限时 60 秒；输出过长会提示继续追问。无流式显示，不自动修改人物卡。

# 3D 骰子

掷骰页支持 d4、d6、d8、d10、d12、d20 多面体，d100 使用两颗 d10；CoC 共用个位骰并展示额外十位骰。由本地 Canvas 计算三维面、投影、光照和滚动旋转，不下载远程模型。自定义其他面数使用数值显示。

原有随机引擎先生成唯一结果，动画再展示相同骰点；这不是刚体物理模拟，动画不会重新决定结果。一次最多展示 8 颗，全部骰点仍在记录中。可关闭 3D，系统减少动态效果偏好会跳过旋转。
