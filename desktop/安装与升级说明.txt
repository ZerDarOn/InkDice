墨骰工坊 0.1.6：安装、升级与卸载

发行形式
- InkDice-Setup-0.1.6-win-x64.exe：安装向导、桌面/开始菜单快捷方式和系统卸载入口。
- InkDice-0.1.6-win-x64.zip：免安装版，完整解压后运行，不要仅复制 EXE。
- 两种形式均附带现有 5E / 5R / CoC 资料，不需要 Node.js 或网页服务器。

安装时的版本检查（不是联网自动更新）
- 未安装：正常安装。
- 已安装低版本：按安装向导升级，沿用原数据目录。
- 已安装同版本：提示是否修复，默认取消；静默调用不重复安装。
- 已安装高版本：提示并阻止降级。
- 安装版本无法识别：停止安装，先人工核对。
- ZIP 免安装版没有安装记录，不自动查找或删除。

卸载
- Windows 设置 → 应用 → InkDice / 墨骰工坊 → 卸载。
- 或开始菜单“墨骰工坊”中的卸载入口。
- 删除程序及快捷方式，保留 %APPDATA%\InkDice 中的人物和用户资料。
- 用户另存的 JSON/Excel 不删除。

不连接更新服务器，不后台检查、下载或安装新版。
首次启动说明只在当前本机配置首次展示，可随时从“关于墨骰工坊”重新查看。
重要人物请先导出 JSON 备份，再升级或迁移。
本次构建与验证详情见交付目录中的发行说明；版本比较测试不等同于所有 Windows 环境的安装验证。
