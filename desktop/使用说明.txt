项目主页：https://github.com/ZerDarOn/InkDice
反馈入口：https://github.com/ZerDarOn/InkDice/issues/new/choose

安装版：运行 InkDice-Setup-0.1.6-win-x64.exe，按向导安装。
免安装版：完整解压 InkDice-0.1.6-win-x64.zip，再双击 InkDice.exe。
请保留 resources、DLL、locales 等随包文件。不需要 Node.js 或网页服务器。

本版更新
- 5E（2014）、5R（2024）与 CoC 七版分别创建人物、查询资料和导出。
- 随包附带现有 5E / 5R SQLite 资料库与 CoC 目录数据，无需手动导入。
- 悬浮球 AI 对话结合当前人物、对应系统资料及启用的资料包；支持追问、来源查看与停止。
- AI 需自行配置兼容服务；密钥只在当前会话保留。发送人物摘要、匹配资料和近期对话，不自动改卡。
- 3D 多面骰和 CoC 百分骰动画展示真实掷骰结果，可关闭动画。
- 支持纯 JSON 资料包导入、启停与移除；尚未开放外部脚本插件宿主。
- 新 Logo、ZerDarOn 署名、首次启动说明及关于页面；关于内可打开 GitHub 反馈。
- 本地安装与卸载入口，安装时比较版本；无联网自动更新。

存档与导出
人物数据保存在 %APPDATA%\InkDice，与程序目录独立。
浏览器旧人物：先导出 JSON，再在桌面程序中导入。不要直接删除旧浏览器数据。
JSON 用于完整备份与迁移；多表 Excel 用于查看、编辑和分享，支持立绘。
Excel 是导出时快照，不包含完整自动化规则引擎，不能作为完整人物卡直接导入。
导出文件名为“角色名-玩家名”，未填写玩家时使用“未填写玩家”。

资料与边界
5E / 5R 数据库位于 resources\library\content-library.sqlite；CoC 数据随应用资源内置。
首次启动自动载入。已有用户资料库按原有保护逻辑备份并合并修复，不强行覆盖自定义正文。
资料与自动化仍可能存在缺漏，不代表覆盖所有出版物或全部规则效果。
AI 可能误解规则，请核对引用与原始资料。插件启停不会撤销已抄入人物卡的内容。
本包不包含个人角色存档、API 密钥或原始 Excel 文件。
本软件为独立开发工具，非相关规则权利方的官方产品。资料权利归各自权利人所有。
本版本未进行数字签名。如遇安全软件拦截，请记录提示反馈，不要关闭保护。
